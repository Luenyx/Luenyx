# Overview
This is a simple TypeScript library focussed on providing good developer experience and easy to reason about code. Verbosity, simplicity, and clarity are the main goals.

This library will produce slow runtime performance due to the class-wrapping of primitives. However, it should enable developers to write more efficient, bug-free code, and build complex structures with less effort.

The code style and API surface is heavily opinionated and does not aim to match the standard JavaScript ecosystem:
- Snake_Case type names
- snake_case value names
- Verbose, descriptive naming
